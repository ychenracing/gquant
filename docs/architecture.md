# 架构与代码结构

## 分工与依赖

```text
命令行 cli
  └─ application：校验、运行、报告与验收的编排
       ├─ engine：按交易日推进账户与风险状态
       ├─ strategy：收盘选股、目标权重、次日订单
       ├─ execution：开盘与独立预置保护的模拟成交
       ├─ portfolio：持仓、可卖数量、现金与订单模型
       ├─ risk：市场状态、组合回撤、个股退出
       ├─ market：行情宽表、因果指标、逐条行情校验
       ├─ research：绩效口径、固定参考、连续区间和成交审计
       └─ infrastructure：配置/行情读取、网络请求、身份和事务发布
```

策略、执行、账户、风控和指标模块不访问命令行、网络或输出目录。基础设施不反向调用回测引擎；研究模块接收已经形成的账本和行情，不复制选股或成交实现。依赖方向和循环依赖由架构测试检查。

| 目录/文件 | 职责 |
|---|---|
| `src/gquant/config.py` | 参数类型与默认值 |
| `src/gquant/application/engine.py` | 会话顺序、账户推进、收盘估值与风险组合 |
| `src/gquant/application/service.py` | 输入准入、一次回测、完整报告发布 |
| `src/gquant/application/validation.py` | 固定参考和诊断编排；同次运行中复用完全相同的配置 |
| `src/gquant/strategy/planner.py` | 卖出、轮动、超配修剪、补仓和新仓预算 |
| `src/gquant/strategy/rotation.py` | 排序目标、ATR 权重和预置保护条件 |
| `src/gquant/execution/` | 数量规范、成本、成交限制、开盘与止损执行 |
| `src/gquant/portfolio/` | `Account`、`Position`、`Order`、`Fill`、`Result` 和卖单合并 |
| `src/gquant/risk/` | `RegimeMachine`、`PortfolioGuard` 和无状态个股退出 |
| `src/gquant/market/` | OHLCV 校验、宽表和滚动指标 |
| `src/gquant/infrastructure/` | CSV/JSON、数据清单、供应商请求、事务输出与身份 |
| `src/gquant/research/` | 绩效、参考门槛、账本约束和连续区间 |
| `tests/` | 单元、执行路径、架构、数据、输入、发布与经济轨迹测试 |
| `data/` | 冻结行情、元数据和 CSV 哈希清单 |
| `evidence/` | 原始研究证据及其使用边界；不进入安装包 |
| `scripts/` | 仓库静态检查与可复现安装包校验 |

## 一天如何运行

窗口开始前的数据用于滚动指标预热，以及建立首日可用的已知价格和成交量。账户和风险状态从完整回放起点开始，随后连续推进；不会用窗口外交易虚构账户收益。进入窗口后：

1. 将隔夜持仓标记为可卖；冻结隔夜组合供预置保护使用。
2. 用当日开盘价执行前一收盘生成的订单。流动性额度只读此前已知的成交量，并累计记录已经消耗的股数。
3. 对前一收盘满足条件的持仓逐只检查预置保护价。某只股票开盘卖出或缺行情，不能撤销另一只已具备的独立保护。
4. 按收盘价估值；缺价持仓只用最近有效价格估值，不据此创造可成交行情。
5. 更新市场、组合回撤、冷却和脉冲状态；形成下一交易日的卖出及买入意图。
6. 保存权益、实际敞口、市场状态和事件，再把当日有效价格与成交量加入已知信息。

`Account` 拥有现金和库存；`ExecutionSimulator` 修改真实模拟成交账本；`OrderPlanner` 拥有趋势连续计数和回补冷却；`PortfolioGuard` 拥有组合峰值、回撤和恢复状态。个股退出函数不修改跨日计数，避免同一天被重复累加。

## 数据与输出边界

业务计算只接受已验证的行情值。应用入口还校验整个快照的文件集合、哈希、行数和日期元数据。新获取数据写入独立目录，不能在研究期间原地替换冻结输入。

报告按“完整代次 + 哈希清单 + 原子指针”发布。写入者通过目录锁互斥；读者验证指针、清单和全部文件，不接受缺失、改写、符号链接跳转或不完整结果。中断后可能留下无引用代次或锁，恢复规则见[运行指南](operations.md)。

这是单机单研究账户的模块化程序，不引入微服务、消息队列、数据库、券商适配器或后台自动交易。完整账户连续性通过从相同起点重放保证；没有宣称支持任意中途持久化账户接续或真实账户同步。
