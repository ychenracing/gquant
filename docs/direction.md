# 研究方向

优先解释连续亏损区间的机制：分别归因到持有错误标的、退出过慢、减仓后追入、交易摩擦与市场共振。先用既有账本分解，再提出一个范围明确的候选改动，与固定基准比较；不以不断增加条件掩盖失败。

其次是事前股池与未见样本验证。记录每个时点可以知道的候选池信息，避免用后来赢家倒选股票；冻结规则后建立连续模拟观察和滚动验证。已经研究过的窗口不能再次被命名成样本外。

第三是执行真实性：收集开盘和保护触价附近的成交机会、滑点、无法成交原因、实际可卖数量，校准容量而不是仅扩大日成交量比例。新的市场数据必须有来源和身份，不能替代已经冻结的验收输入。

工程方向以这些实际研究需要为驱动：需要时再扩展真实账户核对、可靠持久化接续或数据适配器。它们尚未实现，不能把目录或接口规划当作能力已经具备。当前不建设自动下单、多账户多租户、分布式微服务或通用优化平台。
