# 研究方向

第一优先级是**降低主线集中和事后股池偏差**。当前默认窗口约99.67%的模拟净利润来自五只光通信相关股票；应建立事前可执行的候选池规则，并在规则冻结后做前向观察。不要把后来赢家加入池后再称为泛化验证。

第二优先级是**真实执行校准**。人工账户续接和实际成交对账已经具备，后续应持续记录开盘/保护触价附近的实际滑点、未成交、部分成交、可卖数量和公司行动，比较计划订单与实际回报。8%的日量约束是研究代理，不是实际成交能力认证。

第三优先级是**亏损机制归因**。对历史诊断和近期连续亏损区间，分别量化选错股票、退出/回场、风险层切换与交易摩擦的贡献。每次只验证少量明确假设，并保留所有试验结果，避免同一窗口反复挑最优参数。

第四优先级是**简单同条件参照**。继续保留固定买入持有、简单ret63轮动、关闭双持仓保护、逐股剔除和行业代理剔除等诊断，用来判断复杂风险层是否稳定增加价值。诊断不改变正式参考门。

工程改进只服务这些研究与人工决策需求。当前不建设自动下单、多账户多租户、分布式微服务或通用优化平台。
