# 数据合同

## 内容与来源

`data/` 包含41份日线 CSV、`dataset.json` 行数/日期元数据和 `SHA256SUMS` 文件哈希。默认策略观察其中26只股票，核心候选7只；其他股票和两个指数是研究输入，不等于同时进入候选池。

这份冻结输入来自 Tencent 日线快照，成交量采用经过板块单位核对的股数。不是一次 Eastmoney 全量刷新；没有进行实时盘口、分时成交量或市场冲击标定。价格使用供应商提供的复权日线，不能替代完整的分红现金、公司行为及真实券商成交模型。

| 字段 | 含义与要求 |
|---|---|
| `date` | 交易所本地日期，不带时区或时分秒；不得重复 |
| `open/high/low/close` | 开盘/最高/最低/收盘价格，必须有限且大于零，OHLC 相容 |
| `volume` | 成交股数，有限且不小于零；指数零量表示未建模流动性 |
| `amount` | `volume × close` 名义代理，不是实际成交额；执行引擎不使用它 |
| `name` | 展示名称，不参与排序或成交 |

供应商原始列的观测单位为：科创板股票按股，沪市主板及深市股票按手，后两者乘100转为股。冻结 CSV 已完成转换；读取、验证和迁移不再换算。独立 Sina 参考在38只股票、14,125个共同股票交易日上核对：科创板一致，其他股票受手数取整影响最大差50股。独立参考不覆盖全部日期，也不包含 sz300776；区间外沿用观测到的板块约定。供应商以后改变格式时必须重新核对，不能把本次观察当永久保证。

## 校验与缺失行情

`python -m gquant validate-data --data-dir data` 要求文件集合、哈希、元数据、行数、起止日期及每条行情全部一致。未知/重复记录、缺文件、符号链接、非法日期、NaN/Infinity、负成交量、非正价格或不相容 OHLC 都不能进入一次被接受的输入快照。

没有某交易日的记录与“记录内有非法值”不同。宽表可保留某股票当日未观测的空单元，不补造可成交K线；已有持仓用最近有效收盘估值，没有任何可用标价时直接失败。当日开盘执行只读取此前已知价格和成交量，前一个有效观测为零量时仍按零量处理。

## 获取独立数据

```sh
python -m gquant fetch-data --start 2023-12-01 --end 2026-09-07 --output outputs/market-data
```

日期由调用者明确选择。每次请求窗口限制在500个自然日以内，避免超过供应商500根K线的上限；程序检查所有响应后才发布完整代次。网络请求失败、数据校验失败不会更新上次完整指针。少于200条的短历史股票在元数据中列明；若后续研究配置需要缺少的股票，研究运行会失败，不静默缩小股票池。

获取数据需要网络；单元测试使用固定响应，并不证明联网刷新已经发生。下载目录与冻结 `data/` 分开。选择新输入必须明确记录新哈希、研究窗口和配置，不能覆盖用来证明既定经济合同的冻结数据。

数量规范：普通股票按100股取整；科创板买入/部分卖出至少200股，程序也按100股向下取整，不足200股的可卖余额可以一次卖清。这是程序的保守数量实现，不是在声称科创板交易所要求每次增加100股。涨跌停使用价格近似阈值，未实现全部特殊证券、上市阶段或停复牌交易规则。
