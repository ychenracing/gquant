## 收益集中度

默认完整窗口的模拟净利润高度集中。按成交现金流、费用和期末持仓估值独立归因，五只光通信相关股票的利润占比约 **99.67%**：

| 股票 | 约占总净利润 |
|---|---:|
| 源杰科技 | 44.64% |
| 中际旭创 | 21.69% |
| 长飞光纤 | 21.46% |
| 新易盛 | 7.27% |
| 天孚通信 | 4.60% |

这不是“删除某只股票后的边际贡献”。删除股票会同时改变轮动、风险状态和后续持仓，因此仓库另做逐股剔除和行业代理剔除诊断。剔除五只光通信代理后，完整窗口收益约为 **+197.83%**、最大回撤约 **−24.26%**、Sharpe约 **2.06**，说明当前策略的经济优势高度依赖该主线。

固定消融还显示：关闭双持仓保护或改回等权轮动都不会让风险/收益同时变好。这些结果用于解释复杂度价值，不是新的正式参考门。

## 适用边界

核心候选池只有7只、最多持有2只，固定池本身存在事后选择偏差；`ret63` 是单一主排序，尚未证明能稳定发现下一批AI主线。市场状态又由自身科技池构造，因此换池会同时改变选股域和风险观察域。

8%的成交参与率只约束日线模拟成交股数，不证明集合竞价、保护触价瞬间或亿元规模能真实成交。前复权价格适合研究信号，但真实账户的股数、分红、拆送和成交回报必须显式对账；人工账户入口因此要求公司行动和实际成交作为独立事件输入。

优先改进方向是事前股池、冻结规则后的前向验证、真实滑点/无法成交统计，以及对亏损事件的机制归因。不要为了恢复4/4而调整固定参考门、挑选窗口或隐藏正确性修复造成的经济变化。
