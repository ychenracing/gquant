## 成交参与率：限制单只股票全天的模拟成交股数

`fusion/config.py` 是默认参数权威来源。保留 `max_adv_participation=0.08`，同一标的
**全天买入、卖出和预置止损累计**共享前一已知日成交量的8%；零量观测不会被旧正量替代。
`0.0` 只能显式用作 no-cap 诊断，不得替代正式验收。日量代理不等于开盘或止损价可成交认证。

本次独立对照发现：旧候选把“科创板 raw volume 已是股”错误扩大为“全部沪市已是股”，
使8只沪市主板成交量缩小100倍。现恢复这些股票在原 main 快照中的正确股数，科创板已完成
的单位修正保持不动，没有再除以100。38只股票、14,125个重叠标的日通过独立新浪量能对照。
**这是原腾讯快照的离线修复，不是 Eastmoney 全量刷新；OHLC、日期、股票池均未改变。**
依据和覆盖限制见 [成交量审计](data/VOLUME_UNIT_AUDIT.md)。

| 机制 | 当前值 / 语义 |
|---|---|
| 调仓与排名 | daily_rotation；ret63唯一主排序；核心池top-2 |
| 仓位 | ATR风险预算；单票最多50%；无杠杆 |
| 基础权重 | `min(50%, 4.5% / max(ATR%, 2%))`，合计超过目标时只向下缩放 |
| 弱势敞口 | WEAKEN最多80% |
| 双持仓保护 | 前收EWI/MA25-1至少14%、两隔夜持仓20日收益相关性至少0.70 |
| 独立保护价 | 每只自己的前收×95.5%；跳空越线按开盘价，否则预置价，再计滑点/费用 |
| 迟滞 / 尾部 / 通用共同波动层 | 默认关闭；没有新增主排序公式或扩大股票池 |

ATR的4.5%是定仓系数，不是“单笔最多亏4.5%”的保证。相关性保护在开盘订单执行前冻结
隔夜持仓身份；另一只开盘卖出、或当日缺价，都不能取消已武装股票自己的保护。历史参数邻域
研究已经被观察，不能当作独立样本外验证；保护事件也仅有有限的2025年样本。

## 执行正确性

T日收盘产生普通订单，下一可交易日执行。同日新买/加仓不增加当天可卖份额。买入金额加费用
同时受订单自身预算和账户现金限制；未实际退出的持仓仍占用槽位，不能用预计卖出腾出第三仓。
同一标的重复风险退出只保留一个退出意图，不能累加份额、容量或最低佣金。

科创板买单至少200股；部分卖出至少200股，不足200股的可用余额可一次性卖出。引擎仍保留
原有100股取整作为策略数量选择，这比交易所允许的200股以上1股递增更保守，不另行调参。
缺失当日行情时不撮合，持仓用最近有效收盘价估值，完整退出持续顺延。非法OHLCV、非有限
本金/费用、非正净值和非法参与率拒绝进入正常结果。具体交易规则仍是日线近似，不代表逐笔实盘。

CRASH保持统一因果定义：`EWI5日收益<=-12%`，或`宽度<=10%且EWI5日收益<=-3%`。
强趋势直通不能绕过真实CRASH信号；账户高水位、回撤梯、冷却状态不在区间报表中重置。

## 必须保留的失败与风险

**旧8%失败不删除。** `3a7a264...` 的run34124222214为72tests通过、经济0/4；9c00ff47的新CI
复现同样0/4。新发现的主板单位错误解释了缺陷，不能把旧失败工件追认为通过。

**成本余量仍有限。** glmcsm在15bps的MDD约14.415%，已越过14.32%；20bps的MDD约14.641%，
Sharpe约3.665，也不达标。不得称为提高成本后仍全面领先。

**历史诊断窗口仍亏损。** 当前8%的2024-04-01～2025-03-31收益 **-11.4718%**、MDD **-25.9013%**、
Sharpe **-0.1852**。它已被观察，且与研究/目标窗口重叠，不是干净OOS。标准窗口4/4不是泛化证明。

**资金规模诊断仍有失败。** 已记录的8%参与率资金扫描为18/24；无参与率限制的封存扫描
为23/24，不能用后者认证容量。本次命名治理不重新运行资金扫描。扫描仅改变本策略本金，
仍对照各对手固定门槛，不是对手同本金重跑。

固定7只核心池有后视偏差；ret63仍是单一主排序；高相关保护的完整窗口8笔成交集中于2025年，
2026年6～8月的风险控制主要依赖其他既有机制。没有证明能发现下一批AI龙头、风险识别全面优于
四个对手，或亿元资金在开盘实际可成交。历史绝对趋势门、outsider注入和惰性全弱空仓实验保持
被否决/诊断身份，没有为美化泛化而接入新的生产规则。
